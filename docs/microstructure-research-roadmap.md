# 微观结构预测研究路线图

## 目标与边界

使用 ETHUSDT 的1分钟主动成交和Top20订单簿聚合数据，研究指标与未来5分钟价格
收益的关系，最终形成可验证的预测信号。

当前约束：

- 预测目标为 `future_5m_return = close(t+5m) / close(t) - 1`。
- 从当前分钟到5分钟后必须存在六根严格连续、已收盘的1分钟K线，否则标签为空。
- 数据按时间前70%发现、后30%验证，不随机切分。
- 十分位边界只由发现集确定，再原样应用到验证集。
- 暂不使用已采集的5分钟OI，不增加其他数据源。
- 在样本外关系稳定前，不预设异常阈值，不把单个极端点直接定义为异常。

## 六项候选指标

| 顺序 | 指标 | 定义或研究方向 | 状态 |
| --- | --- | --- | --- |
| 1 | 主动成交失衡 | `(主动买入额 - 主动卖出额) / (主动买入额 + 主动卖出额)` | 已实现 |
| 2 | 成交强度 | 当前1分钟成交额 / 前60个连续完整分钟成交额中位数 | 已实现 |
| 3 | 盘口深度快速减少 | 分钟初至分钟末Top20买卖总深度下降比例 | 已实现 |
| 4 | spread异常扩大 | 当前分钟spread P95 / 前60个连续有效分钟spread P95中位数 | 已实现 |
| 5 | Top5盘口失衡 | 1分钟有效快照的Top5买卖盘深度失衡均值 | 已实现，从迁移并重启采集器后积累 |
| 6 | 成交方向与价格变化不匹配 | `主动成交失衡 × 当分钟绝对涨跌幅`，仅保留方向相反分钟 | 已实现 |

每项指标都先执行相同的十分位研究，统计每组样本数、平均未来5分钟收益和上涨比例，
不在实现指标时直接写入异常阈值。

## 数据量与结论等级

数据量是研究成熟度提示，不是六个指标必须同时等到某个固定数量才能开始的硬门槛。
指标可以先实现和验证计算流程，但结论必须随样本规模升级：

| 单项有效样本数 | 用途 | 可以得出的结论 |
| ---: | --- | --- |
| 少于1,000 | 流程验证 | 只确认公式、缺口处理、图表和切分是否正确 |
| 1,000–9,999 | 形态观察 | 可以观察分组形态，不能定义稳定异常阈值 |
| 10,000–29,999 | 初步研究 | 可以评估关系方向和不同市场阶段的一致性 |
| 30,000及以上 | 首轮验证 | 可以进行第一轮样本外稳定性评估，仍不等于可交易结论 |

不同指标的有效样本数可能不同。例如成交强度要求此前60分钟连续，盘口指标要求足够的
订单簿覆盖率，因此不能只用数据库分钟总数代替单项有效样本数。

## 后续落地阶段

### 阶段A：完成六项指标研究

1. 按候选顺序逐项实现指标计算。
2. 接入同一联合页面和相同的70%/30%验证框架。
3. 为缺口、覆盖率、过去数据基准和边界清除增加测试。
4. 保持指标定义因果可用：当前分钟的指标不能使用未来信息。

### 阶段B：持久化与定时快照（已完成）

在历史数据增长到页面实时计算影响响应速度，或需要保留研究版本时再实施：

1. 每日任务先增量补充已经成熟的未来5分钟收益标签。
2. 六项指标共享一次一致的数据读取，并以同一截止时间生成页面就绪结果。
3. 统一调度器每天00:30（Asia/Shanghai）为所有配置币种生成研究快照。
4. 快照保存数据截止时间、样本数、计算版本、耗时和页面所需分组统计，保证结果可追溯。
5. 页面读取最近成功快照并明确展示生成时间与数据截止时间；保留手工生成命令。

### 阶段C：阈值冻结与实时信号

只有某项指标在发现集和验证集中呈现方向一致、极端组有足够样本，并且跨不同市场阶段
仍能复现时，才进入该阶段：

1. 根据发现集确定候选阈值，不使用验证集反复调参。
2. 给阈值定义版本、生效时间、训练区间和适用指标版本。
3. 使用后续未参与阈值选择的数据做最终时间外验证。
4. 每分钟数据完成后应用已冻结阈值，生成异常事件。
5. 异常事件同时记录指标值、阈值版本、数据质量状态和预测方向。
6. 持续统计命中率、平均未来收益、覆盖率和市场阶段表现；失效时停用，而不是自动修改阈值。

## 下一步

六项候选指标的计算、每日快照和联合研究页面已经完成。下一步继续积累数据，优先比较六项指标在
发现集和验证集中的方向、幅度与极端十分位样本数；同时可以在盘口采集页增加“实时指标
观察”面板，先展示当前值、历史分位和数据质量，不在关系尚未稳定时标记正式异常。
